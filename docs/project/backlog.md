# 백로그

MVP 범위(F01–F13)와 단계 6–7의 F14·F20은 들어갔습니다. 이 표는 **지금 열려 있는 것**만 순위대로 담습니다. 끝난 것은 [roadmap](../product/roadmap.md) 단계 표에 있습니다.

## P0 — 문서가 약속한 것이 코드에 없다

| 작업                         | 산출물                      | 완료 기준                                                 |
| ---------------------------- | --------------------------- | --------------------------------------------------------- |
| 휴지통 정리에 로그·인맥 추가 | `RetentionSweeper` + 테스트 | 보존 기간이 지난 `career_logs`·`contacts`가 실제로 지워짐 |

[retention.md](../data/retention.md)와 [privacy-requirements.md](../security/privacy-requirements.md)는 두 표의 정리 순서와 "제3자 개인정보는 보존 기간이 지나면 영구 삭제"를 이미 적어 두었지만, sweeper에는 두 표가 없습니다. 단계 6·7에서 "아직 만들 경로가 없다"며 미룬 것인데 이제 API가 생겼으므로, **사용자가 지운 인맥이 영구 삭제되지 않습니다.** 문서와 코드가 어긋난 유일한 지점이라 가장 먼저 닫습니다.

## P1 — 다음 단계

| 순위 | 작업           | 산출물                                       | 완료 기준                                      | 선행           |
| ---- | -------------- | -------------------------------------------- | ---------------------------------------------- | -------------- |
| P1   | 가져오기 1단계 | 번들 형식, `/imports`, `import.plan`/`apply` | 지원 이력·공고 원문이 한 번에 들어옴 (AI 없음) | 없음           |
| P1   | F15 증언       | `Attestation`, V21, 메일 잡, 공개 응답, 웹   | 증언이 외부 검증 Evidence가 됨                 | ADR-0013 머지  |
| P1   | 가져오기 2단계 | 가져온 문서 층(`VersionAuthor.IMPORTED`)     | 과거 제출물이 편집 가능한 출발점이 됨          | 가져오기 1단계 |

[personal-archive-import](../product/personal-archive-import.md)의 1단계를 F15보다 앞에 둔 이유는 세 가지입니다 — 선행 결정이 없고(F15는 ADR-0013 머지가 전제), AI를 쓰지 않아 위험이 작으며, 214건이라는 실제 적체를 바로 받습니다. 공고 일괄 등록 입구도 같이 풀립니다.

## P2 — 결정이 필요한 것

[career-hub-alignment](../product/career-hub-alignment.md)의 열린 질문에 달려 있습니다. 답이 나오기 전에는 설계만 합니다.

| 작업                    | 선행 결정                                    |
| ----------------------- | -------------------------------------------- |
| 마감 중심 대시보드      | 첫 화면이 축적 현황인가 오늘의 작업 목록인가 |
| 경력기술서 문서 유형    | 없음 (enum 네 곳 + 템플릿, 평범한 작업)      |
| 마감 경과 미제출의 결말 | 상태로 둘 것인가 파생 표시로 충분한가        |
| 지원 건 = 문서 묶음     | 제출 스냅샷이 여러 버전을 묶는가 (ADR 감)    |
| 면접 기록의 자리        | ProofU의 사실인가 iterview의 데이터인가      |
| 가져오기 3·4단계        | 위 "면접 기록의 자리"                        |

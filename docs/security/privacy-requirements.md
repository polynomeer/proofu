# 개인정보 처리 요구사항

- 수집 항목, 목적, 보존 기간, 외부 제공자를 사용자가 이해할 수 있는 언어로 고지합니다.
- 필수 정보와 선택 정보를 구분하고 선택 정보 거부가 핵심 기능을 부당하게 제한하지 않도록 합니다.
- 사용자는 자신의 데이터를 조회, 정정, 내보내기, 삭제할 수 있어야 합니다.
- AI 처리 전송은 목적과 제공자 및 국외 이전 가능성을 실제 운영 구성에 맞춰 고지합니다. 현재 구성(ADR-0008): 제공자 Anthropic, 미국 등 국외 서버에서 추론, API 입력은 학습에 사용되지 않으며 제공자 측 보존은 기본 30일. 기밀 민감도 데이터는 설정(S01)에서 동의한 워크스페이스에 한해 전송하고(동의 시각 기록, 부여 시 재인증), 제한 민감도는 동의와 무관하게 전송하지 않습니다.
- 프로필 연락처(이름·이메일·전화·지역·링크)는 내보내기 파일의 머리글에만 쓰고 AI 제공자에게 전송하지 않습니다. 로그에도 남기지 않습니다.
- 계정 삭제는 활성 데이터, 파생 산출물, 검색 인덱스, 객체 저장소를 포함하는 삭제 작업(`account.purge`, [retention.md](../data/retention.md))으로 수행합니다. 사용자는 설정 화면에서 재인증 후 직접 요청할 수 있습니다.
- 법률 문구와 관할 규정 적용 여부는 출시 국가와 사업 주체 확정 후 법률 검토를 거칩니다.

## 사고 대응

1. 탐지된 이벤트를 등급화하고 관련 로그와 증거를 보존합니다.
2. 노출 범위를 제한하기 위해 세션, 키, 연동 또는 기능을 차단합니다.
3. 영향 데이터, 사용자, 기간, 공격 경로를 조사합니다.
4. 법적 통지 요건과 사용자 안내 필요성을 판단합니다.
5. 복구 후 원인과 통제 실패를 기록하고 재발 방지 작업을 추적합니다.

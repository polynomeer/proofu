# 검색과 적합도 매칭

## 파이프라인

1. 공고 Requirement를 표준 기술과 역량 용어로 정규화합니다.
2. 키워드 전문 검색으로 높은 정밀도의 후보를 수집합니다.
3. 선택적으로 의미 검색을 사용해 표현이 다른 후보를 보완합니다.
4. 최근성, 반복성, 복잡도, 영향 범위, Evidence 품질을 특징으로 계산합니다.
5. 민감도와 공개 범위 필터를 적용합니다.
6. 규칙 점수와 의미 유사도를 결합해 순위를 정하고 근거를 생성합니다.

## 점수

```
MatchScore = 0.30 × RequirementCoverage
           + 0.20 × EvidenceStrength
           + 0.15 × Recency
           + 0.15 × Complexity
           + 0.10 × Impact
           + 0.10 × SemanticSimilarity
```

점수는 정렬 보조 수단이며 합격 확률로 표현하지 않습니다. 각 하위 점수와 사용한 Evidence를 함께 표시하고, 필수 조건이 명시적으로 충족되지 않으면 전체 숫자와 별도로 격차를 보여줍니다. 점수 계산은 `packages/domain`의 순수 함수로 구현하고 단위 테스트합니다.

## 요구사항 분류

| 범주 | 코드 | 예시 | 매칭 규칙 |
|---|---|---|---|
| 필수 조건 | `REQUIRED` | 경력 연수, 특정 자격, 근무 조건 | 충족 / 부분 충족 / 미확인 / 불충족 |
| 우대 조건 | `PREFERRED` | 특정 도메인 경험, 기술 | Evidence 강도와 최근성 |
| 책임 | `RESPONSIBILITY` | 설계, 운영, 협업, 리딩 | 행동과 영향 범위 중심 |
| 기술 | `SKILL` | 언어, 프레임워크, 데이터베이스 | 정규화 이름, 별칭, 버전 |
| 행동 역량 | `BEHAVIORAL` | 소통, 문제 해결, 주도성 | 구체 사례와 제3자 또는 결과 Evidence |

## 품질 평가 데이터셋

- 직군과 경력 수준을 층화한 공고 Requirement 세트를 유지합니다.
- 각 Requirement에 정답 후보 Evidence와 비관련 Evidence를 전문가가 라벨링합니다.
- Recall@K, nDCG, 잘못된 필수 조건 충족 판정률을 측정합니다.
- 모델과 임베딩 변경은 고정 평가 세트 회귀 테스트를 통과해야 합니다.

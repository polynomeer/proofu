# 비기능 요구사항

| 영역 | MVP 기준 | 검증 |
|---|---|---|
| 가용성 | 월간 API 99.5% 목표 | 외부 제공자 장애 제외 기준을 명시합니다. |
| 성능 | 일반 읽기 p95 500ms 이하, 생성 요청 접수 1초 이하 | 부하 테스트와 실제 p95를 측정합니다. |
| 확장성 | 워커 수평 확장과 큐 기반 역압 | 동시 생성 부하에서 실패율을 확인합니다. |
| 복구 | RPO 24시간 이하, RTO 4시간 이하 | 분기 복구 훈련으로 확인합니다. |
| 보안 | 전송·저장 암호화, 최소 권한, 감사 로그 | 출시 전 위협 모델과 권한 테스트를 수행합니다. |
| 호환성 | 최근 2개 주요 브라우저 버전 | 브라우저 매트릭스 E2E로 검증합니다. |
| 내보내기 | 사용자 데이터의 기계 판독 가능한 전체 내보내기 | 샘플 계정으로 복원 가능성을 확인합니다. |

## 식별자와 동시성

- 외부에 노출되는 식별자는 UUIDv7 또는 동등한 비추측 식별자를 사용합니다.
- 모든 변경 가능한 레코드는 `version` 또는 `updated_at` 조건을 이용한 낙관적 잠금을 적용합니다.
- 멱등성이 필요한 생성 API는 `Idempotency-Key`를 받아 동일 결과를 반환합니다.
- 워크스페이스 식별자를 모든 소유 데이터에 포함하고 쿼리 계층에서 격리를 강제합니다.

## 환경 변수 범주

| 범주 | 예시 | 규칙 |
|---|---|---|
| 데이터베이스 | `DATABASE_URL` | 비밀 저장소에서 주입하고 로그 금지 |
| 객체 저장소 | `OBJECT_BUCKET`, `OBJECT_REGION` | 환경별 버킷 분리 |
| 인증 | `OIDC_ISSUER`, `OIDC_CLIENT_ID` | redirect URI 허용 목록 |
| AI | `AI_PROVIDER`, `AI_API_KEY`, `MODEL_POLICY` | 키 회전과 제공자별 예산 |
| 큐 | `QUEUE_URL`, `WORKER_CONCURRENCY` | 역압과 dead letter queue |
| 관측성 | `OTEL_ENDPOINT`, `RELEASE_VERSION` | 개인정보 attribute 금지 |

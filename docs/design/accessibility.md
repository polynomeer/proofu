# 접근성과 콘텐츠

## 접근성 기준

| 항목 | 기준 |
|---|---|
| 대비 | 일반 텍스트 4.5:1 이상, 큰 텍스트 3:1 이상 |
| 키보드 | 모든 기능 접근 가능, 논리적 포커스 순서 |
| 포커스 | 2px 이상 명확한 외곽선, 색상 대비 확보 |
| 클릭 영역 | 최소 44px 권장, Compact 표는 최소 36px |
| 확대 | 200%에서도 기능과 정보 손실 없음 |
| 스크린 리더 | 랜드마크, 제목, 레이블, 표 헤더, 상태 변화 제공 |
| 동작 감소 | `prefers-reduced-motion` 존중 |

## 콘텐츠 원칙

- 메뉴와 버튼은 명사보다 사용자의 행동을 구체적으로 표현합니다.
- AI 추천은 확정, 예측, 추론을 구분하고 신뢰도와 근거를 함께 제공합니다.
- 탈락 원인처럼 알 수 없는 내용은 가능성 또는 가설로 표현합니다.
- 오류 문구는 무엇이 잘못되었는지와 사용자가 할 수 있는 일을 설명합니다.
- Evidence는 제품 고유 개념으로 유지하되 첫 사용 시 "근거 자료"라는 설명을 제공합니다.

## 날짜와 숫자

사용자 화면에서는 로컬 시간대와 한국어 날짜 형식을 사용합니다. 최근 시각은 상대 시간과 절대 시각을 함께 제공할 수 있습니다. 백분율은 소수점 없이 표시하고 세부 화면에서 계산 근거를 제공합니다.

## 화면 검수 기준

1. 확정 로고의 P 기록 레이어와 U 문서 탭이 모든 위치에서 유지됩니다.
2. 주요 화면에서 로열 블루와 청회색 토큰 외 임의의 브랜드 색상이 사용되지 않습니다.
3. 데스크톱 1440px에서 콘텐츠가 과도하게 늘어나거나 잘리지 않습니다.
4. 태블릿과 모바일에서 핵심 행동이 숨겨지지 않고 표의 대체 표현이 제공됩니다.
5. 로딩, 빈 상태, 오류, 권한 없음, 오프라인 상태가 모두 설계되어 있습니다.
6. 키보드만으로 모든 기능을 사용할 수 있고 포커스가 항상 보입니다.
7. 검증과 경고 상태가 색상 외 텍스트 및 아이콘으로 구분됩니다.
8. Evidence와 AI 추천의 원천 및 신뢰도를 확인할 수 있습니다.
9. 버전 저장과 제출 스냅샷이 시각적으로 명확히 구분됩니다.
10. 삭제, 외부 전송, 복구 불가 행동에는 명확한 확인 절차가 있습니다.

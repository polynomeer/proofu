# 컴포넌트 명세

## 버튼

| 유형      | 용도                       | 상태                                             |
| --------- | -------------------------- | ------------------------------------------------ |
| Primary   | 페이지당 한 개의 핵심 실행 | default, hover, active, focus, disabled, loading |
| Secondary | 보조 실행과 취소 전 단계   | default, hover, active, focus, disabled          |
| Tertiary  | 표와 카드의 가벼운 실행    | default, hover, focus, disabled                  |
| Danger    | 삭제, 연결 해제, 철회      | 확인 대화상자와 함께 사용                        |

## 입력

- 레이블은 입력 위에 고정하며 placeholder만으로 의미를 전달하지 않습니다.
- 필수 여부와 도움말은 레이블 영역에서 제공합니다.
- 오류는 테두리, 아이콘, 텍스트를 함께 사용하고 해결 방법을 설명합니다.
- 자동완성은 출처 유형과 일치 구간을 표시하며 키보드로 선택할 수 있어야 합니다.
- 긴 텍스트는 자동 저장 상태와 글자 수가 아니라 내용 구조를 우선 안내합니다.

## 카드와 표

카드는 하나의 목적과 대표 행동만 가집니다. 비교가 필요한 반복 데이터는 카드 대신 표를 사용합니다. 표 헤더는 고정할 수 있으며 정렬, 필터, 열 표시 설정을 제공합니다. 행 전체 클릭과 행 내부 버튼이 충돌하지 않도록 명확한 포커스 순서를 유지합니다.

## 상태 칩

| 상태        | 배경        | 텍스트      | 아이콘        |
| ----------- | ----------- | ----------- | ------------- |
| 검증됨      | success-050 | success-700 | check         |
| 검토 필요   | warning-050 | warning-700 | alert         |
| 만료        | neutral-100 | neutral-700 | clock         |
| 비공개      | neutral-100 | neutral-700 | lock          |
| 제출 스냅샷 | primary-050 | primary-700 | document-lock |

## 사이드바

- 데스크톱 너비 224px 고정. 로고, 1차 메뉴, 설정과 도움말을 배치합니다.
- 선택 항목은 밝은 파란 배경과 흰색 아이콘 및 텍스트를 함께 사용하고, 굵기로도 구분합니다.
- 접힌 상태 72px, 아이콘과 툴팁 제공.
- 모바일에서는 하단 내비게이션 4개와 더보기 메뉴로 재구성합니다.

## 상단 바

전역 검색(경력, 스킬, 회사, Evidence, 채용공고 통합 검색, 결과 유형 그룹), 알림, 사용자 메뉴. 페이지별 주요 생성 버튼은 콘텐츠 헤더 우측에 배치합니다.

## 알림

- **토스트**: 저장 완료처럼 짧고 되돌릴 수 있는 결과.
- **페이지 배너**: 연결 장애, 만료된 Evidence처럼 지속적인 문제.
- **모달**: 파괴적 행동, 데이터 외부 전송, 복구가 어려운 변경에만.
- 동일한 알림을 반복 표시하지 않고 알림 센터에서 이력을 확인할 수 있게 합니다.

## 삭제와 복구

일반 항목 삭제는 소프트 삭제 후 실행 취소를 제공합니다. 제출 스냅샷과 감사 기록은 직접 삭제할 수 없으며 별도의 보존 정책을 따릅니다. 여러 관계를 가진 항목을 삭제할 때는 영향을 받는 Claim과 문서를 먼저 보여줍니다.

## 프론트엔드 계약

- 모든 상태는 서버 enum과 UI 라벨 매핑을 명시하고 알 수 없는 값의 fallback을 제공합니다.
- 자동 저장은 낙관적 UI를 사용하되 충돌 발생 시 서버 버전과 사용자 편집본을 비교합니다.
- AI 응답은 스트리밍 중, 완료, 부분 실패, 취소 상태를 모두 표현합니다.

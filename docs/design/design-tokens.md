# 디자인 토큰

코드 구현: `apps/web/src/styles/tokens.css`. 색상과 간격은 토큰을 통해서만 사용하고 화면별 임의값을 금지합니다.

## 색상

| 토큰        | 값        | 용도                                     |
| ----------- | --------- | ---------------------------------------- |
| primary-600 | `#3B5998` | 주요 버튼, 링크, 선택 상태, 브랜드       |
| primary-800 | `#2D4373` | 사이드바, 진한 브랜드 영역               |
| primary-050 | `#EAF0FA` | 제출 스냅샷 칩 배경, 선택 행 배경 (파생) |
| primary-700 | `#334C85` | 제출 스냅샷 칩 텍스트 (파생)             |
| surface-100 | `#E9EBEE` | 앱 배경, 구획 분리                       |
| surface-050 | `#F3F6FA` | 보조 배경, 필터 영역                     |
| surface-000 | `#FFFFFF` | 작업 영역, 카드                          |
| border-300  | `#D3D8E0` | 카드, 표, 입력 테두리                    |
| text-900    | `#1C1E21` | 본문, 제목, 핵심 수치                    |
| text-600    | `#5B6270` | 보조 정보 (파생)                         |
| success-600 | `#238C5A` | 검증 완료, 성공                          |
| success-700 | `#1C7049` | 검증됨 칩 텍스트 (파생)                  |
| success-050 | `#E8F5EE` | 검증됨 칩 배경 (파생)                    |
| warning-600 | `#B7791F` | 검토 필요, 불완전 상태                   |
| warning-700 | `#926118` | 검토 필요 칩 텍스트 (파생)               |
| warning-050 | `#FBF3E4` | 검토 필요 칩 배경 (파생)                 |
| neutral-100 | `#E9EBEE` | 만료, 비공개 칩 배경                     |

"파생"으로 표시한 값은 원본 문서에 명시되지 않아 대비 기준을 만족하도록 구현 시 정의한 값입니다. Figma 라이브러리와 일치 여부를 검수 항목에 포함합니다.

## 타이포그래피

기본 UI 글꼴은 **Pretendard Variable**. 대체: Noto Sans KR → Apple SD Gothic Neo → sans-serif. 숫자는 `tabular-nums`.

| 역할        | 크기 | 굵기 | 행간 | 사용 예               |
| ----------- | ---- | ---- | ---- | --------------------- |
| 페이지 제목 | 28px | 700  | 1.25 | 커리어 대시보드       |
| 섹션 제목   | 20px | 700  | 1.3  | 커리어 타임라인       |
| 카드 제목   | 15px | 600  | 1.4  | 검증된 Evidence       |
| 본문        | 14px | 400  | 1.55 | 설명과 상세 정보      |
| 보조 정보   | 12px | 400  | 1.45 | 날짜, 파일 크기, 출처 |
| 숫자 강조   | 28px | 700  | 1.1  | 186, 92%              |

## 브레이크포인트

| 구간    | 폭       | 행동                                               |
| ------- | -------- | -------------------------------------------------- |
| Wide    | ≥ 1440px | 4열 KPI와 2열 보조 콘텐츠                          |
| Desktop | ≥ 1200px | 4열 KPI 유지, 상세 열 축소                         |
| Tablet  | ≥ 768px  | 사이드바 접힘, KPI 2열, 표 가로 스크롤             |
| Mobile  | ≤ 767px  | 하단 내비게이션 4개 + 더보기, KPI 1열, 카드형 목록 |

## 아이콘

16px, 20px, 24px 세 크기. 1.5px 또는 2px 스트로크의 선형 스타일. 아이콘만 있는 버튼은 접근 가능한 이름과 툴팁을 제공합니다.

## 밀도

기본 밀도는 Comfort. Evidence 및 지원 관리 화면에는 Compact 전환 옵션을 제공하며, Compact에서도 클릭 영역 높이는 최소 36px를 유지합니다.

# 브랜드

## 디자인 방향

ProofU의 디자인은 **신뢰할 수 있는 경력 기록 시스템**이라는 인상을 최우선으로 합니다. 화면은 로열 블루와 청회색을 중심으로 구성하고, 흰색 작업 영역과 선명한 테두리로 정보 구조를 드러냅니다. 장식보다 데이터의 관계와 상태를 보여주는 데 집중합니다.

| 결정 영역  | 확정 방향                        | 이유                                       |
| ---------- | -------------------------------- | ------------------------------------------ |
| 브랜드     | 확인 미소 심벌 + Nunito 워드마크 | 근거로 확인된 경력을 한 모양으로 표현      |
| 제품 톤    | 전문적이고 차분한 B2B SaaS       | 경력자와 장기 데이터 관리 서비스에 적합    |
| 색상       | 로열 블루, 청회색, 흰색 중심     | 신뢰와 정보 가독성을 동시에 확보           |
| 밀도       | 중간에서 높은 정보 밀도          | 경력 데이터와 지원 현황을 한 화면에서 비교 |
| 내비게이션 | 고정 좌측 사이드바               | 핵심 모듈 간 반복 이동 비용 감소           |
| 상태 표현  | 색상과 텍스트 라벨을 함께 사용   | 색각 차이와 모호한 의미 방지               |

## 디자인 원칙

1. 근거가 먼저 보입니다. 주장이나 추천에는 연결된 Evidence와 검증 상태를 함께 표시합니다.
2. 경력자는 빠르게 비교합니다. 핵심 숫자와 상태를 먼저 보여주고 세부 정보는 점진적으로 공개합니다.
3. 자동화는 설명할 수 있어야 합니다. 추천과 매칭 결과에는 점수뿐 아니라 근거와 부족한 부분을 제공합니다.
4. 모든 변경은 추적할 수 있어야 합니다. 저장 시각, 버전, 원천, 공개 범위와 변경 이력을 노출합니다.
5. 업무 도구처럼 안정적으로 동작해야 합니다. 예측 가능한 배치, 일관된 상태, 명확한 오류 복구를 제공합니다.

## 로고

로고는 **심벌**과 **워드마크**로 이루어집니다. 심벌은 **확인 미소**입니다 — 두 점의 눈과, 확인 표시로 웃는 입. "근거로 확인되어 웃는 나"를 한 표정으로 말합니다. 워드마크는 [Nunito](https://fonts.google.com/specimen/Nunito) ExtraBold(SIL OFL 1.1)를 윤곽선으로 바꾼 것으로, 둥근 획 끝이 심벌의 둥근 눈·미소와 같은 언어입니다. 글자를 늘리거나 바꾸지 않습니다.

원본 벡터는 [`brand/`](brand/)에 있습니다: `proofu-mark.svg`(심벌), `proofu-wordmark.svg`(윤곽선 — 폰트 없이 그려짐), `proofu-app-icon.svg`(스토어 제출용 꽉 찬 사각). 웹은 `apps/web/src/components/brand/Logo.tsx`(`BrandMark`·`Wordmark`·`BrandLockup`)와 파비콘 `apps/web/src/app/icon.svg`로 같은 도형을 씁니다. 도형을 바꾸면 세 곳을 함께 바꿉니다.

### 심벌 구성 (120 격자)

| 요소 | 값                                                                  |
| ---- | ------------------------------------------------------------------- |
| 눈   | 반지름 10, 중심 (45, 36)과 (77, 36) — 눈 사이 22                    |
| 입   | 확인 표시 (28, 66) → (52, 90) → (94, 50), 획 16, 둥근 끝과 꺾임     |
| 틀   | 원·사각 같은 틀 없이 표정만. 앱 아이콘에서만 로열 블루 타일 위에 둠 |

### 캐릭터로 쓰기

심벌은 표정이므로 화면의 일러스트 자리에도 씁니다: 문서의 모든 문장에 근거가 생겼을 때, 기록이 비어 있을 때(흐린 색). **결과를 단정하는 자리(합격·탈락, 회고의 원인)에는 쓰지 않습니다** — 웃는 얼굴이 합격을 암시해서는 안 됩니다. 다른 표정(찡그림·윙크 등)을 새로 만들지 않습니다.

### 사용 규칙

| 구분      | 사용 규칙                                                                       | 금지 사항                           |
| --------- | ------------------------------------------------------------------------------- | ----------------------------------- |
| 기본형    | 로열 블루(`#3B5998`) 단색                                                       | 그라데이션, 그림자, 윤곽선만 남기기 |
| 반전형    | 짙은 파란(`#2D4373`) 바탕 위 흰색                                               | 저대비 회색 또는 투명도 적용        |
| 단색      | 흑백 인쇄·도장에서만 `#1C1E21`                                                  | 눈과 입을 다른 색으로               |
| 조합형    | 가로: 워드마크 높이 = 심벌 높이의 0.62, 간격 = 심벌 너비의 0.25 · 세로형        | 심벌과 워드마크 사이에 다른 요소    |
| 최소 크기 | 심벌만 16px, 가로 조합형 가로 120px, 워드마크 단독 80px                         | 눈이나 입 지우기, 회전, 비율 변형   |
| 여백      | 사방으로 심벌 너비의 0.25 이상                                                  | 다른 아이콘, 문구와 결합            |
| 앱 아이콘 | 로열 블루 바탕에 흰 심벌, 바탕의 70%. 스토어용은 꽉 찬 사각(모서리는 OS가 깎음) | 심벌을 다른 도형 테두리에 가두기    |
| 표기      | **ProofU** (대문자 P와 U 유지)                                                  | Proofu, PROOFU, Proof U             |

시안과 적용 예는 디자인 캔버스의 "스마일 캐릭터"·"E2 확인 미소" 줄(E2, W1)에 있습니다. 상표 검색은 출시 전 할 일입니다([open-decisions](../project/open-decisions.md)).

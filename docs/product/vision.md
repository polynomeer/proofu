# 제품 비전

ProofU는 개인의 경력, 프로젝트, 성과, 기술, 학습, 수상, 자격과 포트폴리오를 장기간 축적하는 **커리어 베이스캠프**입니다. 사용자는 한 번 정리한 사실과 증빙을 재사용해 특정 채용공고에 맞는 이력서와 자기소개서를 만들고, 제출 버전을 보존하며, 서류 결과를 다음 지원의 개선 데이터로 전환합니다.

ProofU는 단순한 이력서 생성기가 아니라, 커리어 사실과 증빙을 관리하고 **모든 지원 문장을 그 근거까지 추적할 수 있는** 커리어 Source of Truth입니다.

## 해결할 문제

- 경력 정보가 여러 문서와 서비스에 흩어져 최신성과 일관성을 잃습니다.
- 채용공고마다 이력서를 다시 작성하면서 사실 확인과 표현 정리에 많은 시간이 듭니다.
- 생성형 AI가 실제 경험에 없는 성과나 기술을 만들어낼 위험이 있습니다.
- 제출한 문서와 당시 사용한 공고 및 원천 데이터의 연결이 남지 않습니다.
- 서류 탈락 후 원인을 구조적으로 기록하지 않아 같은 문제가 반복됩니다.

## 제품 원칙

| 원칙        | 정의                                               | 구현 판단 기준                                              |
| ----------- | -------------------------------------------------- | ----------------------------------------------------------- |
| 사실 우선   | 사용자 사실과 Evidence가 생성 문장보다 우선합니다. | 근거 없는 문장은 최종본에 자동 포함하지 않습니다.           |
| 추적 가능성 | 결과물에서 원천 데이터와 생성 이력을 역추적합니다. | 문장 단위 provenance를 저장합니다.                          |
| 사용자 통제 | 제출 전 모든 문장을 사용자가 승인합니다.           | 자동 제출과 무승인 외부 전송은 MVP에서 제외합니다.          |
| 재현 가능성 | 과거 제출 상태를 그대로 재구성할 수 있어야 합니다. | 공고 원문, 원천 버전, 프롬프트, 모델을 스냅샷으로 남깁니다. |
| 상호운용성  | 데이터를 서비스에 가두지 않습니다.                 | JSON, Markdown, DOCX, PDF 내보내기를 제공합니다.            |
| 설명 가능성 | 적합도와 추천 이유를 Evidence로 설명합니다.        | 숫자 점수만 노출하지 않습니다.                              |

## 목표와 비목표

| 구분   | 내용                                                          |
| ------ | ------------------------------------------------------------- |
| 목표   | 경력 Source of Truth 구축과 증빙 연결                         |
| 목표   | 채용공고별 요구사항 추출과 사용자 Evidence 매칭               |
| 목표   | 근거 기반 이력서·자기소개서·포트폴리오 생성                   |
| 목표   | 버전 비교, 제출 스냅샷, 서류 결과 회고                        |
| 비목표 | 채용 플랫폼을 대신하는 대규모 공고 크롤러 구현                |
| 비목표 | 면접 질문 생성, 면접 녹화 평가 및 합격 이후 분석 (→ iterview) |
| 비목표 | 사용자 승인 없는 자동 지원과 이메일 발송                      |
| 비목표 | 서류 탈락 원인의 확정적 판정                                  |

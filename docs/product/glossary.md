# 용어집

코드 식별자는 이 표의 영문 용어를 그대로 사용합니다.

| 용어 | 정의 | 구분 기준 |
|---|---|---|
| Workspace | 한 사용자의 개인 데이터 경계 | 모든 소유 데이터는 workspace_id를 가집니다. |
| Career Entry | 경력, 학력, 교육, 수상, 자격 등 시간 기반 이력 | 발생 기간과 소속을 가집니다. |
| Project | 목표, 역할, 활동, 결과를 가진 작업 단위 | 한 개 이상의 Career Entry에 연결될 수 있습니다. |
| Achievement | 측정 가능한 결과 또는 검증 가능한 변화 | 행동이 아니라 결과를 설명합니다. |
| Skill | 도구, 언어, 프레임워크, 방법론 등 구체 기술 | 정규화 이름과 사용자 표현을 분리합니다. |
| Capability | 문제 해결, 설계, 협업 등 재사용 가능한 역량 | 여러 Skill과 Evidence를 묶을 수 있습니다. |
| Claim | 사용자가 문서에서 주장하려는 사실 또는 평가 | 사실, 추론, 의견을 구분합니다. |
| Evidence | Claim을 지지하는 문서, 링크, 파일, 수치 또는 기록 | 출처와 검증 상태를 가집니다. |
| Artifact | 포트폴리오, 발표자료, 저장소, 인증서 등 산출물 | 파일 또는 외부 URL로 저장합니다. |
| Job Posting | 특정 시점의 채용공고 원문과 메타데이터 | 변경 가능한 URL과 불변 Snapshot을 분리합니다. |
| Requirement | 공고에서 추출한 책임, 조건, 기술 또는 우대사항 | 원문 구간과 추출 신뢰도를 가집니다. |
| Application | 한 회사 한 포지션에 대한 지원 작업 단위 | 공고, 문서, 제출, 결과를 묶습니다. |
| Document Version | 이력서, 자기소개서 등의 편집 가능한 버전 | 부모 버전과 생성 근거를 가집니다. |
| Submission Snapshot | 실제로 제출한 공고, 문서, 원천의 불변 묶음 | 수정 대신 새 제출을 생성합니다. |
| Review | 지원 결과에 대한 사실, 가설, 개선 행동 기록 | 확정 원인으로 표현하지 않습니다. |
| Provenance | 문서 블록이 참조한 원천 항목과 revision | 생성 후 변경되지 않습니다. |
| Job (비동기 작업) | 공고 분석, 매칭, 문서 생성, 내보내기 등 장시간 작업 | 202 + jobId로 접수하고 `/jobs/{id}`로 조회합니다. |

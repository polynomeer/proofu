# MVP 범위

## 포함

- 이메일 또는 OIDC 로그인과 개인 워크스페이스
- 경력, 프로젝트, 성과, 기술, 학습, 자격, 수상, 포트폴리오 CRUD
- URL·파일·텍스트 기반 Evidence 등록과 주장 연결
- 공고 URL 또는 본문 수동 입력 및 career-ops 가져오기 계약
- 공고 요구사항 구조화와 사용자 수정·승인
- 요구사항별 Evidence 추천과 설명 가능한 적합도
- 이력서 초안 생성, 편집, 승인, 버전 비교
- DOCX, PDF, Markdown, JSON 내보내기
- 지원 상태와 제출 스냅샷 관리
- 서류 결과 기록과 가설 기반 회고

## 제외

- 자동 크롤링 인프라의 신규 구축과 다수 채용 사이트 우회 수집
- 사용자 승인 없는 외부 모델 학습 또는 외부 서비스 전송
- 자동 지원, 자동 이메일, 자동 일정 생성
- 협업 조직 계정과 채용 담당자용 기능
- 모바일 네이티브 앱
- 면접 평가와 답변 코칭 기능
- 합격 가능성 예측과 탈락 원인 확정

## 우선순위 기준

우선순위는 사용자 가치, 사실성 위험 감소, 선행 의존성, 구현 비용을 함께 평가합니다. 점수만으로 자동 결정하지 않고 규제와 보안 위험은 별도 차단 조건으로 취급합니다.

```
Priority = 0.35 × UserValue + 0.30 × TrustRiskReduction + 0.20 × Dependency + 0.15 × Reach − EffortPenalty
```

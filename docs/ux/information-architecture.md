# 정보 구조

```
대시보드
├─ 커리어      경력 프로젝트 성과 학습 자격 수상
├─ Evidence    역량 Claim Evidence 포트폴리오
├─ 채용공고    저장 분석 비교 매칭
├─ 지원 문서   이력서 자기소개서 템플릿 버전
├─ 지원 관리   상태 제출 결과 회고
└─ 설정        계정 개인정보 연동 내보내기 삭제
```

## 1차 메뉴

| 메뉴 | 경로 | 주요 목적 | 대표 하위 기능 |
|---|---|---|---|
| 대시보드 | `/` | 현황과 다음 행동 파악 | 핵심 지표, 타임라인, 최근 Evidence |
| 커리어 | `/career` | 경력 원천 데이터 관리 | 경력, 프로젝트, 성과, 기술, 자격, 학습 |
| Evidence | `/evidence` | 근거 자료 관리 | 업로드, 링크, 검증, 공개 범위, 연결 관계 |
| 채용공고 | `/jobs` | 지원 대상과 요구사항 관리 | 공고 저장, 요구사항 분석, 매칭 |
| 지원 문서 | `/documents` | 문서 생성과 편집 | 이력서, 자기소개서, 버전, 내보내기 |
| 지원 관리 | `/applications` | 지원 과정 기록 | 상태, 제출 스냅샷, 결과, 회고 |
| 설정 | `/settings` | 계정과 개인정보 | 공개 범위, AI 동의, 보존, 내보내기, 삭제 |

## 상호작용 규칙

- AI가 만든 콘텐츠에는 생성 표시와 근거 열람 동작을 제공합니다.
- 저장과 제출은 구분하며 제출 직전 공고, 문서, 개인정보 공유 범위를 다시 확인합니다.
- 파괴적 작업은 대상과 영향을 명시하고 삭제 유예 기간이 있으면 복구 가능 기한을 표시합니다.
- 긴 생성 작업은 비동기 상태와 재시도 가능 여부를 표시하며 화면을 떠나도 진행 상태를 복구합니다.
- 빈 상태는 다음 행동 한 가지를 우선 제시하고 샘플 데이터 사용 여부를 명확히 구분합니다.
- 표 필터, 정렬, 페이지네이션 상태는 URL에 반영해 공유와 복귀가 가능해야 합니다.

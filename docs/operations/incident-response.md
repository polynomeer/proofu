# 장애 Runbook

| 상황           | 즉시 조치                                  | 복구                                                                                                      |
| -------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| AI 제공자 장애 | 새 생성에 지연 표시, 재시도 제한           | 폴백 또는 큐 재처리, 결과 중복 방지                                                                       |
| DB 성능 저하   | 느린 쿼리와 연결 포화 확인, 쓰기 제한 검토 | 인덱스, 롤백, 확장 후 무결성 확인                                                                         |
| 객체 저장 장애 | 업로드와 내보내기 일시 중지                | 참조 누락 검사와 실패 작업 재처리                                                                         |
| 잘못된 배포    | 기능 플래그 해제 또는 이전 artifact 롤백   | 마이그레이션 호환성과 데이터 손상 검사                                                                    |
| 개인정보 노출  | 접근 차단, 키 회수, 증거 보존              | 사고 대응 절차와 통지 판단 실행 ([security/privacy-requirements.md](../security/privacy-requirements.md)) |

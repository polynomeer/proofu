## 도메인 불변식 테스트 (필수)

- 다른 workspace의 Evidence를 Claim에 연결할 수 없습니다.
- 승인 전 Requirement는 최종 매칭 기준으로 사용할 수 없습니다.
- 지원 상태는 정의된 전이만 허용합니다.
- Submission Snapshot은 갱신과 삭제 대신 정책에 따른 별도 삭제 이벤트만 허용합니다.
- Document Version의 provenance source revision은 생성 후 변경되지 않습니다.
- 민감도 기밀 또는 제한 데이터는 허용되지 않은 AI 컨텍스트에 포함되지 않습니다.

## 테스트 데이터 정책

- 프로덕션 개인정보를 개발 또는 테스트 환경으로 복사하지 않습니다.
- 합성 경력, 공고, Evidence 파일을 `fixtures/`로 관리하고 사실성 평가 정답을 버전 관리합니다.
- 외부 연동은 샌드박스와 계약 fixture를 사용하며 네트워크 실패와 지연을 주입합니다.
- 시간과 무작위 식별자는 주입 가능하게 만들어 테스트를 재현합니다 (`Clock`, `IdGenerator`).

### 문서 출력 시각 검증

대표 샘플(한글·영문 이력서, 한글 자기소개서 — 프로필 머리글, 페이지를 넘기는 긴 문단, 한글·영문·숫자·기호 혼합)을 PDF와 DOCX로 만들어 눈으로 확인합니다. 샘플은 합성 데이터이며 파일마다 `ExportValidator`를 함께 통과해야 합니다.

```bash
EXPORT_SAMPLE_DIR=/tmp/proofu-samples ./gradlew :document-renderer:test --tests '*ExportSampleWriter*' --rerun
pdftoppm -r 80 -png /tmp/proofu-samples/resume-ko.pdf /tmp/proofu-samples/resume-ko   # 페이지 이미지
```

같은 폴더에 `<이름>.<형식>.txt`로 재추출 텍스트도 남습니다. 렌더러 라이브러리나 폰트를 바꾸면 바꾸기 전 커밋과 같은 샘플을 만들어 페이지 이미지·재추출 텍스트를 비교합니다.

| 날짜       | 대상                             | 결과                                                                                                                                                                                                               |
| ---------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2026-10-13 | OpenPDF 2.2.2 → 3.0.5            | 페이지 이미지(60dpi 픽셀 비교)·페이지 수·재추출 텍스트 동일. 한글 글리프·머리글·섹션 정상. 긴 문단이 단어 중간이나 하이픈 뒤에서 줄바꿈되면 검증이 실패하던 문제를 고침(`ExportValidator`가 공백을 무시하고 비교). |
| 2026-10-13 | `pdf-openpdf-4` 한글 어절 줄바꿈 | 한글 문단이 어절 사이에서만 줄바꿈됨을 페이지 이미지로 확인. 재추출 텍스트가 원문과 공백까지 같음. 영문 샘플 재추출 텍스트·페이지 수 변화 없음.                                                                    |

알려진 한계: DOCX는 맑은 고딕을 이름으로만 지정하므로(ADR-0009) 이 글꼴이 없는 환경에서는 다른 글꼴로 대체되어 보입니다.

# 핵심 E2E 시나리오

1. 신규 사용자가 경력, 프로젝트, 성과를 등록하고 Evidence 파일을 연결합니다.
2. 공고를 가져와 snapshot을 생성하고 요구사항 추출 결과를 수정·승인합니다.
3. 요구사항별 추천 Evidence와 격차 및 이유를 확인합니다.
4. 추천 항목으로 이력서를 생성하고 unsupported 경고를 해소합니다.
5. 문장을 편집·승인한 뒤 버전을 생성하고 이전 버전과 비교합니다.
6. DOCX와 PDF를 내보내고 텍스트 및 글리프 검증을 통과합니다.
7. 제출 스냅샷을 만든 뒤 원천 데이터를 수정해도 제출본이 변하지 않음을 확인합니다.
8. 서류 탈락 결과와 가설 기반 회고를 기록합니다.
9. 서류 합격 건을 사용자 동의 후 iterview로 한 번만 인계합니다.
10. 전체 데이터를 내보낸 뒤 계정을 삭제하고 접근 불가와 삭제 작업 완료를 확인합니다.

# AI 평가 계획

| 평가 항목   | 측정 방법                                                      | 출시 기준                |
| ----------- | -------------------------------------------------------------- | ------------------------ |
| 사실성      | 생성 Claim이 입력 Claim과 모순하거나 추가 사실을 만드는지 검수 | 중대 오류 0건            |
| 근거 충실도 | 문장 내용이 참조 Evidence 범위 안인지 평가                     | 95% 이상                 |
| 공고 관련성 | 선택 Requirement와 문장의 직접 관련성                          | 평균 4점 이상 (5점 척도) |
| 구체성      | 행동, 역할, 결과가 명확한지 평가                               | 평균 4점 이상            |
| 문체        | 과장, 반복, 상투어와 길이 기준 검사                            | 금지 패턴 통과율 98%     |
| 구조화 출력 | JSON Schema와 참조 무결성 통과                                 | 99.5% 이상               |
| 안전성      | 민감 정보 유출, 프롬프트 인젝션 테스트                         | 중대 실패 0건            |

평가 세트는 `fixtures/ai/`에, 실행기는 우선 `packages/ai-gateway`의 `*EvalTest`(`ANTHROPIC_API_KEY`가 있을 때만 실행)에 둡니다.

## 실행

```bash
export ANTHROPIC_API_KEY=...   # 셸에서만. 인자로 넘기거나 파일에 커밋하지 않는다
scripts/ai-live-check.sh       # SDK 스모크 → 추출 평가 → 설명·초안·문장 개선 평가
```

| 실행기                          | 세트                    | 기계가 판정하는 것                                                                                                                                      | 사람이 읽는 것                              |
| ------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `AnthropicModelClientLiveTest`  | 인라인 공고             | 요청 형식(캐시된 시스템 프롬프트, document 블록, 스키마 출력)이 수락되는지                                                                              | 출력 JSON                                   |
| `RequirementExtractionEvalTest` | `fixtures/ai/postings`  | 기대 인용 재현율 ≥ 90%, 금지 항목 0건, 모든 항목의 원문 구간 해결                                                                                       | 항목별 분류·인용                            |
| `LivePromptEvalTest`            | `fixtures/ai/scenarios` | 설명: 제안 쌍마다 1개·버림 0 / 초안: 섹션 ≥ 2·컨텍스트 밖 참조 0·certainty 상한 보정 0·새 수치 0 / 문장 개선: 가드 통과·수치 보존·(SHORTEN이면) 더 짧음 | 설명 문장, 초안 블록, 개선 문장과 변경 이유 |

기계 판정은 근거화 정책의 하한이고, 사실성·관련성·구체성·문체는 위 표대로 사람이 출력을 읽고 채점합니다. 회당 비용은 $0.5 미만(Opus 5)이며 `ai_executions`에는 기록되지 않습니다(테스트 recorder는 콘솔 출력만). 평가 세트가 커지면 `packages/ai-evaluation`으로 분리합니다. 개인 실제 데이터는 동의 없이 공용 평가 세트에 포함하지 않습니다. 모델과 프롬프트 변경은 고정 평가 세트 회귀 테스트를 통과해야 합니다.
